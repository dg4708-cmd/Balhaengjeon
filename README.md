# 발행전 (Balhaengjeon)

네이버 블로그·스마트스토어 원고를 **발행하기 전 30초**에 점검하는 무료 검사 도구입니다.

- 라이브: https://dg4708-cmd.github.io/Balhaengjeon/
- 검사 항목: 검색 구조 · 저품질 위험 · AI 티 · 가독성
- 회원가입 없음, 입력한 글은 서버로 전송되지 않습니다(모든 계산은 브라우저에서 실행).
- 원클릭 교정본: 문장마다 줄바꿈, 상투어 제거, 중복 문장 정리
